# Meu primeiro dashboard

O processo de criação de um painel simples para acompanhar indicadores.

<!-- more -->

## Definindo o objetivo antes de abrir o Power BI

Antes de montar qualquer visual, defini uma pergunta clara que o painel deveria responder. Sem isso, é fácil acabar com um dashboard bonito, mas que não ajuda ninguém a decidir nada.

## Etapas que segui

1. Organizar e modelar os dados (relacionamentos entre tabelas).
2. Criar medidas simples com DAX.
3. Escolher poucos visuais, bem escolhidos, em vez de muitos.
4. Testar se alguém de fora entenderia o painel sem explicação.

## Aprendizado principal

Um bom dashboard não é sobre mostrar tudo — é sobre destacar o que importa.
