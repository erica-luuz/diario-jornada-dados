# Meu mapa de estudos em dados

Até aqui, meus estudos foram bastante aleatórios: um pouco de cada coisa, sem uma ordem definida. Tenho contato com várias ferramentas — Excel, Google Sheets, Looker Studio, Power BI, Python, SQL e Apps Script —, mas ainda não domino nenhuma como gostaria. Neste post organizo o caminho que pretendo seguir daqui para frente.

> Meu roadmap não é um cronograma rígido. É um mapa para orientar meus estudos, acompanhar minha evolução e registrar o que aprendi ao longo do caminho.

<!-- more -->

## Meu objetivo

Primeiro, crescer e dominar melhor a área como analista de dados. Depois, dar o próximo passo rumo à engenharia de dados, aprendendo ferramentas como o Databricks.

## Como vou estudar

Tenho de 1 a 2 horas por dia para estudar. Por isso, a ideia é manter uma frente principal de cada vez, aprofundando em vez de abrir vários assuntos ao mesmo tempo. Não vou estipular prazos: o objetivo é aprender, não cumprir um cronograma.

## Visão geral

| Etapa | Foco | Status |
|---|---|---|
| 01. Fundamentos | SQL + Estatística básica | Em andamento |
| 02. Python para Dados | Pandas + análise + gráficos | Próxima |
| 03. BI e Visualização | Power BI + Looker Studio | Próxima |
| 04. Automação e Integração | APIs + Apps Script + ETL + Git | Futuro |
| 05. Projetos | Projetos reais para portfólio | Contínuo |

## Detalhando as etapas

### 01. Fundamentos: SQL + Estatística básica

**SQL e fundamentos de dados**

- SELECT, WHERE e ORDER BY
- GROUP BY e agregações
- JOIN
- Subqueries
- CTEs
- Window Functions

**Estatística básica**, estudada em paralelo, principalmente quando eu começar a analisar bases:

- Média, mediana e desvio padrão
- Correlação

### 02. Python para Dados

- Pandas e limpeza de dados
- NumPy
- Matplotlib e Seaborn
- Análise exploratória de dados (EDA)

### 03. BI e Visualização

**Power BI**

- Power Query
- Modelagem e relacionamentos
- DAX
- KPIs
- Dashboards
- Storytelling com dados

**Looker Studio**

- Dashboards
- Filtros
- Métricas
- Visualização

### 04. Automação e Integração de dados

- Google Apps Script
- APIs
- Python para automação
- ETL
- Git e GitHub

### 05. Projetos (contínuo)

Ao longo de todas as etapas, quero aplicar o que aprendo em projetos reais para o meu portfólio. O primeiro será um estudo de caso simples de análise de vendas.

## Depois: rumo à engenharia de dados

Com a base de análise mais sólida, o próximo passo é a engenharia de dados:

- Databricks: PySpark, Delta Lake, notebooks e workflows
- Modelagem de dados
- Noções de computação em nuvem

## Uma observação

Este mapa vai mudar conforme eu aprender o que funciona melhor para mim, e isso faz parte do processo. Vou atualizá-lo por aqui sempre que precisar.
